# The core's default XAddiVortes settings

The core's default XAddiVortes settings

## Usage

``` r
xaddivortes_defaults()
```

## Value

A named list: every setting of
[`xaddivortes_params()`](https://l-thomson.github.io/thiessen/r/reference/xaddivortes_params.md)
and its default, as the core defines them.

## Examples

``` r
xaddivortes_defaults()
#> $rounds
#> [1] 40
#> 
#> $max_columns
#> [1] 3
#> 
#> $centres
#> [1] 64
#> 
#> $value_scale
#> [1] 0.5
#> 
#> $replace_share
#> [1] 0.3
#> 
```
