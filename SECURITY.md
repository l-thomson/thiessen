# Security policy

## Supported versions

The latest release of each component (core crate, Python package, R
package) receives security fixes. Nothing is published yet; until the
first release, `dev` is the supported line.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories
(Security tab, "Report a vulnerability") or by email to
hello@leothomson.dev. Do not open a public issue. You will receive an
acknowledgement within a week.
